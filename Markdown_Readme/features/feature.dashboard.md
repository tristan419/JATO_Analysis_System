## Summary
Root cause: load_slice(limit=500_000) used scanner.head() which on hive-partitioned datasets (by country) reads partitions alphabetically. The first 6 countries filled the 500k limit, causing the remaining 15 countries to be completely missing from grouped time-series aggregation. Fix: added limit=None support to load_slice (uses scanner.to_table() for unlimited scan) and changed query_grouped_time_series + _query_grouped_share_time_series to pass limit=None instead of 500_000.
